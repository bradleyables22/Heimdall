# HeimdallFramework.Bootstrap

`HeimdallFramework.Bootstrap` provides strongly typed Bootstrap class helpers for server-rendered .NET applications.

The helpers map to Bootstrap class names and are designed to improve discoverability and composition without replacing Bootstrap or controlling application markup. The package does not include Bootstrap CSS or JavaScript; applications supply those assets separately.

> [heimdall-framework.org](https://heimdall-framework.org) is the source of truth for supported helpers, examples, compatibility, and integration guidance. This package README intentionally stays general so it remains accurate between releases.

## Install

```bash
dotnet add package HeimdallFramework.Bootstrap
```

The class helpers can be used independently. Examples that use Heimdall's fluent HTML rendering also require `HeimdallFramework.Server`.
