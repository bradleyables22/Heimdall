# Heimdall 5.1.0

This release adds concise attribute authoring for Blazor, MVC, Razor Pages, and hand-authored HTML.
The core retains canonical attribute identities and C# helpers continue emitting long-form names.

## Packages

| Package | Version | Change |
| --- | --- | --- |
| HeimdallFramework.Rendering | 5.1.0 | Shared fluent attributes, Razor Tag Helper, fragment helpers, and typed Blazor content adapters |
| HeimdallFramework.Server | 5.1.0 | Transitive dependency on Rendering 5.1.0 |
| HeimdallFramework.Web | 5.1.0 | Shared attribute registry, plugin aliases, and optional default shortcuts |
| HeimdallFramework.Bootstrap | 5.0.1 | Existing version; no new Bootstrap package in this release |

All packages target .NET 10. Applications referencing Server receive Rendering transitively.
Use the matching 5.1.0 Web package when adopting attribute aliases or the new shortcuts scripts.

## Blazor and Razor authoring

Add `@using Heimdall.Server.Rendering` to `_Imports.razor`, then use native attribute splatting:

```razor
<button @attributes='Heimdall.OnClick("orders.refresh").Target("#orders")'>Refresh</button>
```

For MVC and Razor Pages, register the import and Tag Helper in `_ViewImports.cshtml`:

```cshtml
@using Heimdall.Server.Rendering
@addTagHelper *, Heimdall.Rendering
```

```cshtml
<button heimdall='Heimdall.OnClick("orders.refresh").Target("#orders")'>Refresh</button>
```

The Tag Helper assembly name is `Heimdall.Rendering`, while its package is `HeimdallFramework.Rendering`.
Keep existing MVC Tag Helper registrations. The helper preserves normal attributes, child content,
form actions, input helpers, and antiforgery output. Explicit canonical attributes win.
In Blazor, put explicit attributes after `@attributes` when they should override the supplied values.
Custom components must capture and forward unmatched attributes to their native HTML element.

The facade exposes every existing Heimdall element method, immutable reusable configurations,
`SyncGroup`, and local-time configuration with separate `FallbackText`. Razor fills empty time elements
automatically; Blazor renders `FallbackText` explicitly or uses the complete `LocalizedTime` content helper.
`Fragment` and its convenience methods expose the full response fluent API. `Markup` and `MarkupAsync`
adapt trusted typed HTML for Blazor; response directives execute through the normal invocation/SSE pipeline.

See [the complete authoring guide](../razor-blazor-authoring.md) for all methods, async composition,
encoding, reuse, null configurations, and time fallbacks.

## HTML shortcuts and the shared registry

Load the optional plugin after core:

```html
<script src="/_content/HeimdallFramework.Web/heimdall-bundle.min.js"></script>
<script src="/_content/HeimdallFramework.Web/heimdall-shortcuts.min.js"></script>
```

It automatically installs `hd.shortcuts`, covering all 38 built-in element attribute names and the
named-state prefix. The package includes readable and minified core/shortcut scripts and public TypeScript
declarations. Applications can instead configure aliases directly through `Heimdall.attributes`.
Plugins share the registry through trigger `aliases` and installation-scoped `api.attributes`.

Original attributes remain valid and take precedence over aliases. Explicit overrides, idempotent undo,
atomic registration, named-state prefix mappings, and provider cleanup support team conventions.
Late registration and removal reconcile existing elements. Response directive and native HTML names
keep their existing contracts.

See [Attribute Shortcuts](../attribute-shortcuts.md) for every mapping and registry method, and
[Frontend Plugins](../frontend-plugins.md) for ownership and installation rules.

## Upgrade notes

- Existing canonical markup, FluentHtml element chains, and response directives continue using their
  current names and behavior. Standalone configurations are immutable; assign or chain returned values.
- `PreventDefault(false)`, `VisibleOnce(false)`, and `SseDisable(false)` now retain an explicit `false`
  attribute so runtime defaults and earlier fluent values can be overridden.
- If a fully qualified Razor model namespace starts with `Heimdall`, use `global::Heimdall...` or import
  the model namespace and use its simple name. C# code can use a namespace-local facade alias:
  `using Heimdall = global::Heimdall.Server.Rendering.Heimdall;`.
- Aliases are optional. Typed C# authoring does not require the shortcuts plugin. Load scripts in order
  and deploy matching core/shortcut assets together.

## Release artifacts

Release packages and symbol packages are prepared under `artifacts/releases/5.1.0/`.
`SHA256SUMS.txt` records their hashes and `release-manifest.json` records package metadata, dependencies,
and source revision. The release directory contains only the three updated libraries and their symbols.
NuGet publication is a separate step.
